# 口調パターン（10種類）

条件入力の「口調」で選べるパターン。アプリで使う内容は `lib/tones.js` にあり、ここを直したらそちらも合わせて直す。

口調の違いは語尾だけにしない。各パターンに専用の【冒頭フック型】【リズム】【絵文字】【決めフレーズ】【NG表現】【締め方】【お手本】を持たせる。絵文字は固定のものを毎回入れず、口調の候補から文章の感情・場面に合うものを選び、パターンA・B・Cで組み合わせを変える。

投稿を作るときは、選んだパターンの指示をひな型に足す。ひな型の文字数（160〜200文字）と改行ルール（1文目の後だけ改行）は必ず守る。1文目はひな型の固定文にせず、口調側の【冒頭フック型】を優先する（悩みの特定は必ず入れる）。文脈構成の6段階は目安にして自然な日本語でつなげる。決めフレーズは本文の途中（2文目か3文目）に必ず自然に入れる。

## 1. 親しみやすいお姉さん系（女性 / 仲良くなりたい・共感）

- ペルソナ: 距離感が近く、リアルな失敗談を共感交えて話してくれる頼れるお姉さん。
- トーン: カジュアル、共感多め、語尾は「〜なんだよね」「〜してみて！」

【口調指定】
距離感が近く親しみやすいお姉さん口調で書いてください。読者の悩みに寄り添い、「私も全く一緒だったよ！」という共感を重視します。
語尾：「〜なんだよね」「〜じゃない？」「〜してみてね！」

【冒頭フック型】
1. 「ねえ、〜で悩んでない？」と友達に話しかけるように呼びかける
2. 「私もずっと〜だったんだけど」と自分の悩みから先に明かす
3. 「〜の人、ちょっと聞いて」と当事者だけに絞って呼び止める

【リズム】短めの文を柔らかくつなぐ。疑問形を2回まで使い、読者と会話している感じにする。
【絵文字】🥹 🫶 ✨ 💓 🌱 から選ぶ。悩みへの共感は🥹、感動・嬉しさは💓や🫶、締めの後押しは✨。1投稿に2個まで。同じ絵文字を2回使わない
【決めフレーズ】「私も全く一緒だったよ」（本文の途中に必ず入れる）
【NG表現】言い切りで断定する表現／「絶対」「必ず」などの煽り／上から目線の命令口調
【締め方】「まずこれ試してみてね！」と優しく背中を押し、読者が自分用に保存したくなる一言で締める。

【お手本】
ねえ、朝起きると喉がカラカラで肌もつっぱる人、私も全く一緒だったよ！🥹
加湿器は高いと思って我慢してたし、水を入れるだけの簡単ケアも続かなかったんだよね。でも2,980円の卓上加湿器を枕元に置いたら、朝の喉のイガイガが全然違うの。給水も週2回で済むし、特にエアコンの日は差が出たよ。寝る前のひと手間で朝が変わるって、こういうことなんだよね。乾燥で寝苦しいならまずこれ試してみてね！🫶

【文脈構成】
1. 「ねえ、〜で悩んでない？」と親しく問いかける
2. 自己流で試して撃沈した話を明かす
3. 別のバズり方法を試すもイマイチだったエピソード
4. たまたま見つけたきっかけを嬉しそうに語る
5. 使ってみた感動と納得感（やっぱこれ！）
6. 「絶対試してみて！」と優しく背中を押す

## 2. 本音炸裂の女子会トーク系（女性 / 続きが聞きたい・リアル感）

- ペルソナ: テンションが高めで、良いことも悪いことも包み隠さず話す友人。
- トーン: ポップ、感情豊か、語尾は「〜なの！」「〜だったんだけど（笑）」

【口調指定】
仲の良い友達に女子会で秘密を明かすような、テンションが高くリアルな本音口調で書いてください。
語尾：「〜なの！」「〜なんだけど」「まじで〜」

【冒頭フック型】
1. 「待って、〜って私だけ！？」と驚きで切り出す
2. 「正直に言うと、〜でまじで萎えてた」と本音を暴露する
3. 「ちょっと聞いて、〜が想像以上だった」と秘密話の形で始める

【リズム】テンポ速め。短文と感嘆を混ぜ、感情のアップダウンを大きくする。
【絵文字】😳 🤣 ✨ 💓 🔥 から選ぶ。驚きは😳、自虐・失敗は🤣、熱弁の締めは🔥。1投稿に2個まで、テンションに合わせて毎回組み合わせを変える
【決めフレーズ】「期待してなかったのに手のひら返しレベル」
【NG表現】丁寧語・敬語／落ち着いた説明口調／感情のない箇条書き風の言い方
【締め方】「これ知らないの損だよ！」と熱量高く言い切り、友達に教えたくなる勢いで締める。

【お手本】
待って、朝の喉カラカラ、私だけじゃなかった！？😳
正直、高い加湿器じゃないとダメだと思って我慢してたんだけど、2,980円の卓上加湿器を枕元に置いたら朝のイガイガが全然違ったの！給水も週2回で済むし、期待してなかったのに手のひら返しレベル。エアコンの日でも肌がつっぱらないし、朝のメイクのノリまで違う気がしたの。これ知らないの損だよ！🔥

【文脈構成】
1. 最近本気で困っていたことを暴露
2. 最初にとった間違った行動と失敗を自虐気味に話す
3. ネットで評判の別案を試してガッカリした話
4. 正直期待せずに軽い気持ちで試した運命の出会い
5. 「待って、すごすぎ」という手のひら返しの納得
6. 「これ知らないの損だよ！」と熱弁

## 3. 落ち着いたコスメ・美容ライター系（女性 / 信頼・説得力）

- ペルソナ: 丁寧で品があり、ロジカルに良いものを評価する大人の女性。
- トーン: 丁寧語、洗練された表現、語尾は「〜です」「〜かもしれません」

【口調指定】
落ち着きと品のある丁寧な語り口で書いてください。感覚だけに頼らず、客観的な視点と信頼感を意識します。
語尾：「〜ですね」「〜でした」「〜をおすすめします」

【冒頭フック型】
1. 「〜でお悩みの方は少なくありません」と悩みを静かに言語化する
2. 「〜だと思い込んでいませんか」と思い込みを優しく問い直す
3. 悩みの場面を1つ具体的に描いてから始める

【リズム】文はやや長めで整える。感嘆符は使わず、理由と結果を順序立てて伝える。
【絵文字】使わない（絵文字ゼロで品と信頼感を保つ）
【決めフレーズ】「選んだ理由は、続けやすさです」
【NG表現】絵文字／「まじで」「やばい」などの俗語／根拠のない断定や誇張
【締め方】「同じ悩みの方におすすめします」と静かに、しかし確実に勧めて締める。

【お手本】
朝起きたときに喉の乾燥や肌のつっぱりを感じる方は、少なくありません。
高価格帯の加湿器でなければ効果がないと思い込んでいた私が出会ったのが、2,980円の卓上加湿器です。枕元に置くだけで朝の喉の不快感が和らぎ、給水も週2回で済みました。選んだ理由は、続けやすさです。価格と手入れの手軽さの両面で納得でき、乾燥が気になる方におすすめします。

【文脈構成】
1. 多くの人が抱える具体的な悩みを提示
2. 定番の対策を講じたものの満足できなかった経験
3. 別の話題の手法も期待ほどではなかったこと
4. ふとしたきっかけでこの商品と出会った経緯
5. 実際に使って実感した明確な理由と納得感
6. 悩みを持つ方へ静かに、かつ確実なお勧め

## 4. 頼れるアニキ・検証系（男性 / 信頼・説得力）

- ペルソナ: 自分で色々試した上で、結論だけを分かりやすく教えてくれる頼もしい男性。
- トーン: 言い切り、論理的、語尾は「〜だ」「〜なんだよな」「〜だぞ」

【口調指定】
頼れる兄貴分のような、言い切り型で説得力のある男性口調で書いてください。無駄な装飾を省き、結論をはっきり伝えます。
語尾：「〜だ」「〜なんだよな」「〜してみてくれ」

【冒頭フック型】
1. 「〜な奴、それ○○が間違ってる証拠だ」と原因を言い切る
2. 「結論、〜は要らない」と最初に結論を置く
3. 「〜で苦労してるなら聞け」と検証者として呼び止める

【リズム】短文で言い切る。修飾語を削り、数字と比較で説得する。
【絵文字】使わない（絵文字ゼロで言い切りの強さを保つ）
【決めフレーズ】「俺が試して残ったのはこれだ」
【NG表現】絵文字／「〜かもしれません」などのあいまい表現／かわいらしい語尾や丁寧すぎる敬語
【締め方】「迷ってるなら一回試してみろ」と短く強く背中を押して締める。

【お手本】
朝起きて喉がカラカラな奴、それ部屋の乾燥を放置してる証拠だ。
結論、高い加湿器を買う必要はない。俺が試して残ったのはこれだ、2,980円の卓上加湿器だ。枕元に置くだけで朝のイガイガが違うし、給水は週2回で済む。面倒な手入れで挫折した俺でも続いたんだから間違いない。高い物が正解とは限らない、いい例だ。迷ってるなら一回試してみろ。

【文脈構成】
1. 「〜で苦労してないか？」と問いかける
2. 自力で力押しして失敗した体験談
3. 評判の良い別ルートを試すも不発だった話
4. ふとした瞬間に気づいた盲点
5. 「結論、これが正解だった」という圧倒的納得
6. 「迷ってるなら一回試してみろ」と背中を押す

【リズム】話し言葉のリズム。スペックや手順を1つだけ具体的に入れ、体感を中心に語る。

## 6. 謙虚なレビューブロガー系（男性 / 信頼・誠実）

- ペルソナ: 失敗談を包み隠さず話し、慎重に評価を下す誠実なブロガー。
- トーン: です・ます調、誠実、語尾は「〜でした」「〜と感じました」

【口調指定】
誠実で誇張のない、丁寧なレビューブロガー口調で書いてください。読者の目線に立った客観的な語り口です。
語尾：「〜でした」「〜と感じています」「〜と思います」

【冒頭フック型】
1. 「〜で長年、地味に悩んでいました」と期間を示して始める
2. 「最初に試した○○は、正直続きませんでした」と失敗から入る
3. 「結論を急がずに言うと」と慎重な姿勢を見せて始める

【リズム】落ち着いた長めの文。良かった点だけでなく、続かなかった理由も正直に入れる。
【絵文字】使う場合は ✨ 🌱 のみ、1投稿に1個まで。無理に入れず、ゼロでもよい（誠実さ優先）
【決めフレーズ】「試す価値はあると思います」
【NG表現】「絶対」「神アイテム」などの誇張／断定的な効果の約束／感情的な煽り
【締め方】「同じ悩みを持つなら、試す価値はあると思います」と控えめに推奨して締める。

【お手本】

【文脈構成】
1. 長年解決しなかった悩みの共有
2. 最初に試した方法で失敗した苦い経験
3. 別の対策も効果が限定的だったこと
4. 知人の一言や偶然の検索で知ったきっかけ
5. 実際に継続して納得に至ったポイント
6. 「同じ悩みを持つなら試す価値あり」と誠実に推奨

## 7. ストーリーテラー・語り部系（男女共通 / 続きが聞きたい・引き込み）

- ペルソナ: 読者を物語に引き込み、思わず最後まで読ませる文章のプロ。

【口調指定】
読者を惹きつけるストーリーテリング形式の口調で書いてください。起承転結を意識し、展開に引き込みます。
語尾：「〜だったのです」「〜はずでした」「〜でしょうか」

【冒頭フック型】
1. 「もう〜な夜は終わりにしたい。そう思っていたはずでした」と物語の予告で始める
2. 絶望的な場面を1文で描いてから始める
3. 「あの朝が、変わるきっかけになるとは」と結末を匂わせて始める

【リズム】緩急をつける。短い文で場面を切り替え、転機の文だけ少し長くドラマチックに書く。
【絵文字】🥹 🌙 ✨ から選ぶ。絶望・悩みは🥹、転機や夜の場面は🌙、締めは✨。1投稿に1個だけ、物語の転機か締めに置く
【決めフレーズ】「霧が晴れるように、これだと確信した瞬間」
【NG表現】箇条書きのような事務的な説明／結論を最初に言い切る書き方／俗っぽい煽り言葉
【締め方】「あなたもこの変化を体感すべきです」と物語の外の読者へ呼びかけて締める。

【お手本】

【文脈構成】
1. 絶望的な悩みの描写からスタート
2. 最初の挑戦と、無情な失敗の記録
3. 期待を込めた第二の矢も折れたエピソード
4. 諦めかけたその時舞い降りた奇跡のきっかけ
5. 霧が晴れるように「これだ」と確信した瞬間
6. 「あなたもこの変化を体感すべきです」と締めくくる

## 8. 先輩・メンター系（男女共通 / 信頼・指導）

- ペルソナ: 後輩の悩みを先回りして解決してくれる、温かく知的な先輩。

1. 「〜でつまずいてない？」と優しく察する

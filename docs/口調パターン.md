# 口調パターン（10種類）

条件入力の「口調」で選べるパターン。アプリで使う内容は `lib/tones.js` にあり、ここを直したらそちらも合わせて直す。

投稿を作るときは、選んだパターンの【口調指定】と【文脈構成】をひな型に足す。ひな型の文字数（160〜200文字）と改行ルール（1文目の後だけ改行）は必ず守り、文脈構成の6段階はなるべく目安にして自然な日本語でつなげる。

## 1. 親しみやすいお姉さん系（女性 / 仲良くなりたい・共感）

- ペルソナ: 距離感が近く、リアルな失敗談を共感交えて話してくれる頼れるお姉さん。
- トーン: カジュアル、共感多め、語尾は「〜なんだよね」「〜してみて！」

【口調指定】
距離感が近く親しみやすいお姉さん口調で書いてください。読者の悩みに寄り添い、「私も全く一緒だったよ！」という共感を重視します。
語尾：「〜なんだよね」「〜じゃない？」「〜してみてね！」

【文脈構成】
1. 「ねえ、〜で悩んでない？」と親しく問いかける
2. 自己流で試して撃沈した話を明かす
3. 別のバズり方法を試すもイマイチだったエピソード
4. たまたま見つけたきっかけを嬉しそうに語る
5. 使ってみた感動と納得感（やっぱこれ！）
6. 「絶対試してみて！」と優しく背中を押す

## 2. 本音炸裂の女子会トーク系（女性 / 続きが聞きたい・リアル感）

- ペルソナ: テンションが高めで、良いことも悪いことも包み隠さず話す友人。
- トーン: ポップ、感情豊か、語尾は「〜なの！」「〜だったんだけど（笑）」

【口調指定】
仲の良い友達に女子会で秘密を明かすような、テンションが高くリアルな本音口調で書いてください。
語尾：「〜なの！」「〜なんだけど」「まじで〜」

【文脈構成】
1. 最近本気で困っていたことを暴露
2. 最初にとった間違った行動と失敗を自虐気味に話す
3. ネットで評判の別案を試してガッカリした話
4. 正直期待せずに軽い気持ちで試した運命の出会い
5. 「待って、すごすぎ」という手のひら返しの納得
6. 「これ知らないの損だよ！」と熱弁

## 3. 落ち着いたコスメ・美容ライター系（女性 / 信頼・説得力）

- ペルソナ: 丁寧で品があり、ロジカルに良いものを評価する大人の女性。
- トーン: 丁寧語、洗練された表現、語尾は「〜です」「〜かもしれません」

【口調指定】
落ち着きと品のある丁寧な語り口で書いてください。感覚だけに頼らず、客観的な視点と信頼感を意識します。
語尾：「〜ですね」「〜でした」「〜をおすすめします」

【文脈構成】
1. 多くの人が抱える具体的な悩みを提示
2. 定番の対策を講じたものの満足できなかった経験
3. 別の話題の手法も期待ほどではなかったこと
4. ふとしたきっかけでこの商品と出会った経緯
5. 実際に使って実感した明確な理由と納得感
6. 悩みを持つ方へ静かに、かつ確実なお勧め

## 4. 頼れるアニキ・検証系（男性 / 信頼・説得力）

- ペルソナ: 自分で色々試した上で、結論だけを分かりやすく教えてくれる頼もしい男性。
- トーン: 言い切り、論理的、語尾は「〜だ」「〜なんだよな」「〜だぞ」

【口調指定】
頼れる兄貴分のような、言い切り型で説得力のある男性口調で書いてください。無駄な装飾を省き、結論をはっきり伝えます。
語尾：「〜だ」「〜なんだよな」「〜してみてくれ」

【文脈構成】
1. 「〜で苦労してないか？」と問いかける
2. 自力で力押しして失敗した体験談
3. 評判の良い別ルートを試すも不発だった話
4. ふとした瞬間に気づいた盲点
5. 「結論、これが正解だった」という圧倒的納得
6. 「迷ってるなら一回試してみろ」と背中を押す

## 5. 等身大の趣味・ガジェット好き系（男性 / 仲良くなりたい・オタク感）

- ペルソナ: 好きなものを熱量高く語る、ちょっとお茶目で親しみやすい男性。
- トーン: フランク、体感重視、語尾は「〜なんですよね」「〜でした（笑）」

【口調指定】
趣味の合う友人に熱弁するような、フランクで親しみやすい男性口調で書いてください。
語尾：「〜なんですよね」「〜しちゃいました」「〜です！」

【文脈構成】
1. 地味にストレスだった悩みを打ち明ける
2. 知識不足で失敗したお茶目なエピソード
3. 定番品に浮気したけど満足いかなかった話
4. たまたまタイムラインで見かけたのがきっかけ
5. 「もっと早く買えばよかった」という感動
6. 「仲間には全員使ってほしい！」と熱唱

## 6. 謙虚なレビューブロガー系（男性 / 信頼・誠実）

- ペルソナ: 失敗談を包み隠さず話し、慎重に評価を下す誠実なブロガー。
- トーン: です・ます調、誠実、語尾は「〜でした」「〜と感じました」

【口調指定】
誠実で誇張のない、丁寧なレビューブロガー口調で書いてください。読者の目線に立った客観的な語り口です。
語尾：「〜でした」「〜と感じています」「〜と思います」

【文脈構成】
1. 長年解決しなかった悩みの共有
2. 最初に試した方法で失敗した苦い経験
3. 別の対策も効果が限定的だったこと
4. 知人の一言や偶然の検索で知ったきっかけ
5. 実際に継続して納得に至ったポイント
6. 「同じ悩みを持つなら試す価値あり」と誠実に推奨

## 7. ストーリーテラー・語り部系（男女共通 / 続きが聞きたい・引き込み）

- ペルソナ: 読者を物語に引き込み、思わず最後まで読ませる文章のプロ。
- トーン: ドラマチック、緩急がある、語尾は「〜だったのです」「〜とは…」

【口調指定】
読者を惹きつけるストーリーテリング形式の口調で書いてください。起承転結を意識し、展開に引き込みます。
語尾：「〜だったのです」「〜はずでした」「〜でしょうか」

【文脈構成】
1. 絶望的な悩みの描写からスタート
2. 最初の挑戦と、無情な失敗の記録
3. 期待を込めた第二の矢も折れたエピソード
4. 諦めかけたその時舞い降りた奇跡のきっかけ
5. 霧が晴れるように「これだ」と確信した瞬間
6. 「あなたもこの変化を体感すべきです」と締めくくる

## 8. 先輩・メンター系（男女共通 / 信頼・指導）

- ペルソナ: 後輩の悩みを先回りして解決してくれる、温かく知的な先輩。
- トーン: 落ち着いたアドバイス、温かみ、語尾は「〜だよ」「〜ごらん」

【口調指定】
後輩や年下のアドバイスをするような、温かく知的な先輩口調で書いてください。
語尾：「〜なんだよ」「〜してみるといいよ」「〜じゃないかな」

【文脈構成】
1. 「〜でつまずいてない？」と優しく察する
2. 昔自分がやって失敗した遠回りを明かす
3. よくある間違った対処法（別案）への指摘
4. 自分がブレイクスルーを迎えたきっかけ
5. 「やっぱり本質はここなんだよね」という納得
6. 「遠回りせずに、これ試してみて」と導く

## 9. トレンドに敏感なインフルエンサー系（男女共通 / 仲良くなりたい・続き）

- ペルソナ: SNSでバズっているものをいち早く試し、テンポよく紹介するタイプ。
- トーン: テンポが良い、短文、絵文字映えする、語尾は「〜すぎ」「〜必見」

【口調指定】
SNSの投稿のような、テンポが良く感嘆詞を交えたインフルエンサー風の口調で書いてください。
語尾：「〜すぎた」「〜なの」「〜チェックして！」

【文脈構成】
1. 「みんなこれ困ってない！？」とキャッチーに開始
2. 自分で試して大失敗した黒歴史
3. 流行りの別案も微妙だったリアルな感想
4. DMやコメントで教えてもらった神アイテム
5. 「もっと早く知りたかった…」と大満足
6. 「絶対後悔させないからやってみて！」と拡散を促す

## 10. ひそひそ話・内緒の教え系（男女共通 / 続きが聞きたい・限定感）

- ペルソナ: 特別な情報や穴場テクニックを「ここだけの話」として教えてくれる人物。
- トーン: 秘密めいた、語りかける、語尾は「〜なんです」「〜ですよ…」

【口調指定】
「ここだけの話」を明かすような、秘密めいた特別感のある口調で書いてください。読者との心理的距離を極限まで縮めます。
語尾：「〜なんですよね」「〜秘密ですよ」「〜かもしれません」

【文脈構成】
1. 「実は誰にも言えなかった悩み」から切り出す
2. 一般的な解決策で撃沈した話
3. 巷で話題の方法もイマイチだった裏話
4. 本当に偶然手に入れた裏ルートのようなきっかけ
5. 「やっぱり本物は違う」と確信した瞬間
6. 「試すなら今のうちですよ」と限定感を出して促す
